# trading-alert
## 재테크 모닝 브리핑 (`news_digest.py`)

한국시간 기준 월~금 00:10에 전날(KST 00:00~23:59) 국내·해외 주요 뉴스를 각각 최대 10건씩
이메일로 보냅니다. 토요일·일요일·한국 공휴일에는 발송하지 않습니다(공휴일은 무료 공공 API로
그날그날 확인).

**발송 시각에 대해:** GitHub Actions의 예약 실행(`schedule`)은 정확한 시각을 보장하지 않으며,
실제로 이 저장소는 예약 시각보다 3.5~6시간씩 늦게 실행되는 경우가 잦았습니다. "06~07시 KST
사이 발송"을 지키기 위해 그 지연분을 감안해 크론을 00:10 KST로 훨씬 이르게 잡아뒀습니다(지연이
거의 없는 날엔 새벽 일찍 올 수 있습니다). 더 정확한 시각 보장이 필요하면 외부 스케줄러(예:
cron-job.org)가 `workflow_dispatch`를 정시에 호출하도록 바꾸는 방법도 있습니다.

- 출처: 연합뉴스·매일경제·동아일보·조선일보·한겨레 공식 RSS(경제 섹션 + 국제 섹션)뿐입니다.
  해외 원문 매체(CNBC 등)는 기계 번역 품질 문제로 쓰지 않습니다 — 해외 뉴스도 전부 한국 언론사가
  직접 쓴 기사만 사용해 번역 과정 자체가 없습니다.
  RSS 주소를 확인할 수 없었던 매체(중앙일보·아시아경제), 경향신문(요청에 따라 제외)은 뺐습니다.
  한국경제(hankyung.com)는 "한경PREMIUM9" 개편 이후 유료 여부가 페이지 소스만으로 안정적으로
  구분되지 않아(로그인 전에도 본문이 그대로 보이는 기사가 많음) 출처 목록에서 아예 뺐습니다.
- **무료 기사만 선정합니다.** 각 후보 기사는 URL과 원문을 확인해 "구독", "로그인 후", "멤버십",
  "유료", "회원가입" 등의 문구나 유료 섹션 URL이 있거나 본문이 아예 열리지 않으면 제외합니다.
- 메일 제목: `[모닝 브리핑] YYYY-MM-DD(요일) 국내·해외 주요 뉴스`
- 본문: `{날짜(요일)} 국내 주요 뉴스` → 국내 1~N번, 각 항목은 `번호. 제목(클릭하면 원문 링크)` 아래에
  핵심 내용 최대 3줄 + `출처 : 매체명 (발행 월일·시각)` → `{날짜(요일)} 해외 주요 뉴스` → 해외
  1~N번(동일 양식) → 주요 시장 지표(코스피·코스닥·S&P500·나스닥·다우·원/달러·달러인덱스·WTI·브렌트·
  미 10년물·금, 전일 대비)
- **국내·해외 건수는 보통 같습니다.** 둘 다 최대 10건까지 뽑되, 무료 기사가 부족해 한쪽이 10건에
  못 미치면 다른 쪽도 그 개수에 맞춰 자릅니다(예: 국내 10건, 해외 8건이면 국내도 8건만 표기).
  단, 그렇게 맞추면 국내·해외 각각 최소 5건이라는 기준 밑으로 떨어지는 경우에는 동수를 맞추지
  않고 각자 모은 만큼(최대 10건) 그대로 보냅니다 — 최소 5건 확보가 동수보다 우선입니다. 부족하다는
  안내 문구는 쓰지 않습니다.
- **유료 API를 쓰지 않는 무료 방식입니다.** 뉴스 선정은 다음 네 가지를 가중합산한 점수로 순위를
  매깁니다: 정확도 30%(매체 신뢰도), 경제 영향 30%(환율·금리·유가·반도체·증시 등 재테크 키워드
  가중치), 관심도 25%(같은 주제를 다룬 다른 후보 기사 수로 근사), 신선도 15%(그날 후보 중 상대적
  발행 시각). 헤드라인 자체에 재테크 키워드가 없으면 제외합니다(본문에만 스친 단어로는 안 뽑힘).
  같은 사건을 다룬 기사(주제가 겹치거나 헤드라인에 같은 회사가 나오거나 제목이 비슷한 경우)는 그중
  헤드라인이 더 길고 구체적인 쪽 1건만 남깁니다. 이렇게 걸러도 국내·해외 각 10건을 못 채우면,
  완전히 같은 사건의 재탕만 피하고 나머지는 점수 높은 순으로 채웁니다(다양성보다 "건수를 채우고
  주요 주제가 통째로 빠지지 않는 것"이 우선입니다).
  출처가 한국 언론사의 "경제" 섹션이든 "국제" 섹션이든, 기사 주체가 해외(미 연준·나스닥 등,
  한자 국가 약어 포함)면 해외 뉴스로, 국내면 국내 뉴스로 분류합니다(섹션이 아니라 내용 기준).
  URL은 항상 원문 링크 그대로입니다.

GitHub 저장소 Settings → Secrets and variables → Actions에 필요한 값:

| Secret | 설명 |
| --- | --- |
| `GMAIL_ADDRESS`, `GMAIL_APP_PASSWORD` | 기존 발송용 Gmail 계정 |
| `NEWS_MAIL_TO` | 뉴스 브리핑 수신 주소 (필수, 매매 신호용 `MAIL_TO`와 별개. 여러 개는 쉼표로 구분) |

Actions 탭 → `daily-news-digest` → **Run workflow**로 바로 테스트할 수 있습니다.
- 주말/공휴일에도 강제로 보내려면 `force_send` 체크박스를 켭니다.
- `NEWS_MAIL_TO`를 건드리지 않고 특정 주소로만 1회 테스트 발송하려면 `mail_to_override`에 주소를 입력합니다.

로컬에서 `DRY_RUN=1 python news_digest.py`로 실행하면 메일 대신 본문을 출력합니다.
