# trading-alert
## 재테크 모닝 브리핑 (`news_digest.py`)

한국시간 기준 월~금 07:45에 전날 국내 주요 뉴스 7건, 해외 주요 뉴스 7건을 이메일로 보냅니다.
토요일·일요일·한국 공휴일에는 발송하지 않습니다(공휴일은 무료 공공 API로 그날그날 확인).

- 국내 출처: 연합뉴스·한국경제·매일경제·동아일보·조선일보·한겨레 공식 RSS
- 해외 출처: 위 국내 언론사의 "국제" 섹션(이미 한글) + CNBC·MarketWatch·WSJ·BBC·NYT(번역).
  쿠키 동의창이나 페이월로 요약을 못 가져오는 매체(Bloomberg 등), RSS 주소를 확인할 수 없었던 매체(중앙일보·아시아경제)는 제외했습니다.
- 메일 제목: `[모닝 브리핑] YYYY-MM-DD(요일) 국내·해외 주요 뉴스`
- 본문: `{날짜(요일)} 국내 주요 뉴스` → 국내 1~7번(헤드라인 클릭 시 원문 연결, 출처 표기)
  → `{날짜(요일)} 해외 주요 뉴스` → 해외 1~7번(동일 양식) → 주요 시장 지표(코스피·코스닥·S&P500·나스닥·다우·원/달러·달러인덱스·WTI·브렌트·미 10년물·금, 전일 대비)
- **유료 API를 쓰지 않는 무료 방식입니다.** 뉴스 선정은 재테크 키워드(환율·금리·유가·반도체·증시 등) 점수로,
  헤드라인 자체에 키워드가 없으면 제외합니다(본문에만 스친 단어로는 안 뽑힘). 같은 이슈(주제가 겹치거나
  헤드라인에 같은 회사가 나오는 기사)는 원칙적으로 1건만 뽑되, 그래도 7건에 못 미치면 단계적으로 완화해
  최소 7건을 채웁니다(후보 자체가 모자라면 있는 만큼만).
  해외 뉴스는 모두 한국어로 발송됩니다: 국내 언론사의 국제 보도를 우선 쓰고, 부족하면 해외 매체 기사를
  무료 번역기(Google 번역, 차단 시 MyMemory로 자동 전환)로 옮깁니다.
  출처가 한국 언론사여도 기사 주체가 해외(미 연준·나스닥 등, 한자 국가 약어 포함)면 해외 뉴스로 분류합니다.
  URL은 항상 RSS 원문 링크 그대로입니다.

GitHub 저장소 Settings → Secrets and variables → Actions에 필요한 값:

| Secret | 설명 |
| --- | --- |
| `GMAIL_ADDRESS`, `GMAIL_APP_PASSWORD` | 기존 발송용 Gmail 계정 |
| `NEWS_MAIL_TO` | 뉴스 브리핑 수신 주소 (필수, 매매 신호용 `MAIL_TO`와 별개. 여러 개는 쉼표로 구분) |

Actions 탭 → `daily-news-digest` → **Run workflow**로 바로 테스트할 수 있습니다.
- 주말/공휴일에도 강제로 보내려면 `force_send` 체크박스를 켭니다.
- `NEWS_MAIL_TO`를 건드리지 않고 특정 주소로만 1회 테스트 발송하려면 `mail_to_override`에 주소를 입력합니다.

로컬에서 `DRY_RUN=1 python news_digest.py`로 실행하면 메일 대신 본문을 출력합니다.
